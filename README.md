## 快速体验

### 前端链路演示

```bash
cd demo
python3 -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

入口点「开始演示」→ 落地页模拟后退 → 进入劫持页。

### 跳转中控

```bash
cd zhongkong
python3 server.py
# 打开 http://127.0.0.1:8877/admin/
```

后台改落地 URL →「一键下发」→ 打开任意入口壳页，会加载统一的 `/jump.js` 跳到新目标。

## 一句话

**入口用 200 壳页 + 外链 JS + `setTimeout`；落地用 `pushState('#')` + `popstate` 劫持后退；站群用中控改一份脚本让所有入口一起变。**
