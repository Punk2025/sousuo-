# 跳转中控实验室

教学演示：站群如何「一处配置、批量入口一起跳转」。

完整技术笔记：[docs/站群跳转中控.md](../docs/站群跳转中控.md)  
开源对照：[docs/相关开源与资料.md](../docs/相关开源与资料.md)

```bash
cd zhongkong
python3 server.py
```

打开：http://127.0.0.1:8877/admin/

| 地址 | 作用 |
|------|------|
| `/admin/` | 中控后台 |
| `/jump.js` | 所有入口共用的跳转脚本（改配置即变） |
| `/entry/<域名>` | 模拟某入口壳页 |
| `/land/12.html` | 落地页（含后退劫持） |

流程：后台改落地 URL → 点「一键下发」→ 打开任意入口壳页 → 自动跳到新目标。
