## 1. 先说结论

公开 GitHub / Gitee **很难找到**和黑产同款、且持续维护的「一整套」：

> 空壳入口 + 外链 JS 延迟跳转 + `pushState` 后退劫持 + 域名矩阵中控一键下发

原因很直接：完整博彩 / SEO 导流面板多在私下售卖，不会正经开源。

能找到的，多半是**拆开的零件**：

| 你想找的 | 公开仓库情况 |
|----------|----------------|
| 上述黑产链路一整套 | 基本没有可维护的同款开源 |
| 中控批管跳转的产品形态 | 有 → 合法**短链 / 多域名跳转后台** |
| 批量入口站 / 养站 | 有 → **站群 CMS** |
| 劫持手法本身 | 有 → 小型教学 PoC |
| 检测 / 反伪装 | 有论文与少量研究项目；完整工程偏少 |

本地 `zhongkong/` 的价值是把常拆开的两段（入口壳 + 中控下发）捏在一起便于理解；要更完整工程能力，宜参考短链中控 + 站群 CMS，而不是指望有一份开源「博彩跳转面板」。

## 3. 「中控形态」更完整：合法短链 / 多域名跳转

运营模型接近真实站群中控：**多域名、批量、渠道/统计、一处改目标**。  
技术路径多为 **HTTP 302 / 短链**，不是「空壳 + 外链 JS」。

| 项目 | 说明 |
|------|------|
| [muleiwu/dwz-server](https://github.com/muleiwu/dwz-server) | 多域名短链、后台、统计、AB 等，工程较完整 |
| [maiizii/sublink](https://github.com/maiizii/sublink) | 多域名 + 子域跳转统一管理 |
| [hwdemtv/smart-link-manager](https://github.com/hwdemtv/smart-link-manager) | 域名 / 链接 / 配额等偏 SaaS 形态 |
| [Libw-I/UrlShort](https://github.com/Libw-I/UrlShort) | Cloudflare Workers；可配置直链 302 或 JS 跳转 |

学习「后台怎么批管跳转」时，优先看这类。

## 4. 「站群」更完整：批量建站 / 养站 CMS

管的是**内容入口矩阵**（批量建站、模板、SEO），通常**不包含**我们拆的那套 JS 跳转中控。

| 项目 | 说明 |
|------|------|
| [thinkincloud/cmssuper](https://github.com/thinkincloud/cmssuper) | 超级站群；文案明确养站、养域名、批量站 |
| [yingluoyun/aff-cms](https://github.com/yingluoyun/aff-cms) | 海外推广向站群、一键建站 |
| [liweiyi/chestnutcms](https://github.com/liweiyi/chestnutcms) | 正规企业级多站点 CMS，可参考站群结构 |
| 若依系站群 CMS（如 RuoYi-fast-cms 一类） | 政务 / 正规站群场景，多站点与跳转链接管理 |

真实黑产链路常见组合：

```text
站群 CMS 养大量入口  →  再挂私有跳转中控 / 外链 JS
```

公开开源里很少把「养站 + 导流中控」绑成一套。
