# SearchPipe 使用教程

本文档面向 **Mac 用户**，从零安装到日常使用的完整说明。

---

## 一、这是做什么的？

SearchPipe 是一套**本地搜索管线工具**：

1. 用本机浏览器（Playwright + Chromium）搜索百度，抓取排名结果
2. 生成**表格报表**（关键词、排名、域名、链接），可导出 HTML / CSV
3. 可选**规则打标**：识别跳转壳站、疑似成人、博彩、TG、USDT 等
4. **搜索记录**：每次新搜索前，上次结果自动归档，主面板只显示本次

> 定位：研究、识别、报表。**请勿用于违法用途。**

## 二、Mac 一键安装

### 2.1 准备

| 要求 | 说明 |
|------|------|
| 系统 | macOS（Apple 芯片 / Intel 均可） |
| 网络 | 首次安装需联网（下载 Python 依赖 + Chromium，约 1GB） |
| 磁盘 | 建议预留 **2GB** 空闲空间 |
| Python | **不需要提前安装**，脚本会自动处理 |

### 2.2 获取项目

**方式 A：一条命令从 GitHub 下载并安装（推荐）**

打开「终端」，粘贴回车：

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Punk2025/sousuo-/main/mac/bootstrap.sh)"
```

会自动：克隆到 `~/SearchPipe` → 安装 Homebrew / Python / 依赖 / Chromium → 创建桌面快捷方式。

指定安装目录（可选）：

```bash
INSTALL_DIR=~/Desktop/搜索网 /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Punk2025/sousuo-/main/mac/bootstrap.sh)"
```

若目录已存在，会 `git pull` 更新后重新跑安装流程。

**方式 B：Git 克隆后安装**

```bash
git clone https://github.com/Punk2025/sousuo-.git ~/SearchPipe
cd ~/SearchPipe
chmod +x mac/install.sh Mac一键安装.command
./mac/install.sh
```

**方式 C：直接拷贝**  
把整个项目文件夹复制到目标 Mac（U 盘、网盘、AirDrop 均可）。

### 2.3 双击安装

1. 打开项目根目录
2. **双击 `Mac一键安装.command`**
3. 若系统提示「无法打开」：
   - **右键**该文件 → **打开** → 再点 **打开**
   - 或在「系统设置 → 隐私与安全性」里允许运行
4. 终端窗口会自动弹出，按提示操作

### 2.4 安装过程中会发生什么？

脚本会依次执行：

```
检查 Python 3.9+
    ↓ 没有则继续
安装 Homebrew（Mac 包管理器）
    ↓ 可能要求输入 Mac 登录密码
安装 Python 3.12
    ↓
创建虚拟环境 pipeline/.venv
    ↓
安装 Flask、Playwright 等依赖
    ↓
下载 Chromium 浏览器（约 1GB，只需一次）
    ↓
在桌面创建 SearchPipe.command 快捷方式
    ↓
询问是否立即启动
```

**首次大约 3～8 分钟**（视网络速度而定）。之后启动只要几秒。

### 2.5 安装完成标志

终端出现：

```
✅ 安装完成！
是否现在启动控制面板？[Y/n]
```

桌面会出现 **`SearchPipe.command`** 图标。

## 三、启动与停止

### 3.1 启动（三种方式）

| 方式 | 操作 |
|------|------|
| 桌面快捷方式 | 双击 **`SearchPipe.command`** |
| 项目内 | 双击 **`启动SearchPipe.command`** 或 **`一键运行.command`** |
| 终端 | 在项目根目录执行 `./run.sh` |

启动后会：
- 自动打开浏览器，进入控制面板
- 地址：**http://127.0.0.1:8878/admin/**

> 若浏览器没自动打开，手动访问上面的地址即可。

### 3.2 停止

在运行 SearchPipe 的**终端窗口**里按 **`Ctrl + C`**。

关闭浏览器标签页**不会**停止后台服务，必须 Ctrl+C。

## 四、控制面板概览

左侧导航：

| 区块 | 作用 |
|------|------|
| **① 搜索** | 输入关键词，搜百度出报表 |
| **② 表格报表** | 查看 / 导出 HTML、CSV |
| **搜索记录** | 历史归档，回看、下载、删除 |
| **原始 CSV** | 机器抓取底稿 |
| **③ 后续处理** | 可选打标 |

顶部**反馈条**和**进度条**会实时显示当前在做什么（搜索中 / 出报表 / 打标中）。

## 五、完整使用流程

推荐顺序：**搜索 → 导出报表 →（可选）打标**

### 5.1 单词搜索

1. 在 **① 搜索** 区域的输入框填入关键词，例如 `加拿大28`
2. 点击 **「单词出报表」**
3. 会弹出一个 **Chromium 浏览器窗口**，自动打开百度并搜索
4. 等待抓取完成（进度条会更新）
5. 切到 **② 表格报表**，即可看到结果

### 5.2 批量搜索

1. 在 **批量关键词** 文本框里，**一行一个词**（也支持逗号分隔）：
   ```
   加拿大28
   开元棋牌
   澳门威尼斯人
   ```
2. 设置 **每词抓取条数**（默认 20，范围 5～50）
3. 点击 **「批量出报表」**
4. 多个词会排队执行，进度显示「词 2/5」这类信息

### 5.3 从文件导入关键词

1. 点击 **「导入 txt / csv」**，选择文件
2. 点击 **「解析到上方」**，关键词会填入批量文本框
3. 再点 **「批量出报表」**

**文件格式：**

| 格式 | 规则 |
|------|------|
| `.txt` | 一行一个关键词 |
| `.csv` | 优先读「关键词」列；没有则用第一列 |

### 5.4 导出报表

搜索完成后，进入 **② 表格报表**：

- **导出可点击 HTML**：浏览器打开，链接可直接点
- **导出 CSV（Excel）**：用 Excel / Numbers 打开

表格列包括：关键词、排名、名称、域名、分类、入口链接、最终链接。

### 5.5 可选：打标

如果只需要排名列表，**到导出这步就够了**，不必打标。

需要识别跳转 / 成人 / 博彩时：

1. 进入 **③ 后续处理**
2. 确认选项（见下方「打标参数说明」）
3. 点击 **「开始打标」**
4. 完成后，**② 表格报表** 的「分类」列会更新，统计数字也会变化

### 5.6 查看搜索记录

- 点击左侧 **「搜索记录」**，或访问 http://127.0.0.1:8878/admin/history/
- 每次**新搜索开始前**，当前报表会自动归档到这里
- 可对历史记录：**查看详情 / 下载 CSV / 打开 HTML 快照 / 删除**

> 搜索记录**不会自动过期**，会一直留在本机 `pipeline/data/history/`，需要时可手动删除。

## 六、验证码怎么处理？

百度有时会弹出验证码。

1. **不要勾选「无头模式」**（默认就是不勾，会弹出有界面浏览器）
2. 验证码出现在 **Chromium 窗口**里，手动点选完成
3. 完成后程序会自动继续抓取

若验证码一直过不去：

1. 展开 **「备用：验证码过不去时，手动粘贴网址」**
2. 自己在浏览器搜百度，把结果网址一行一个粘贴进去
3. 点击 **「写入报表」**

## 七、打标参数说明

| 选项 | 默认值 | 说明 |
|------|--------|------|
| 只跑前 N 条 | 0 | 0 = 全部；试跑可填 10 |
| 并发 | 8 | 同时抓几个站，1～16；机器慢可调低到 4 |
| 仅当前关键词 | 不勾 | 勾上只打标某一个词的结果 |
| **快速模式** | **勾上** | 推荐保持勾选，速度更快 |
| 优先 Crawl4AI | 不勾 | 更慢、更容易卡住，**不建议勾** |

打标完成后，可按 **仅跳转 / 仅成人 / 仅博彩** 筛选明细。

### 打标分类说明

| 分类 | 识别依据（摘要） |
|------|------------------|
| 跳转壳站 | 空壳页 + JS `setTimeout` / `location` 跳转 |
| 疑似成人 | 标题或页面含成人/色情相关词 |
| 博彩内容站 | 开元、加拿大28、百家乐等关键词 |
| 抓取失败·疑似成人 | 页面打不开，但 SERP 标题像成人站 |
| TG / USDT | 落地页文案信号 |

很多结果站本身已失效，抓取失败是正常现象；程序会尽量按标题补标。

## 八、资源占用（心里有数）

| 状态 | CPU / 内存 | 说明 |
|------|------------|------|
| 后台开着但闲着 | 很低 | 只有 Flask 进程 |
| 正在搜百度 | **高** | Chromium 浏览器占 300MB～800MB+ |
| 正在打标 | **中** | 网络并发请求 |
| 已停止（Ctrl+C） | 无 | 完全不占资源 |

不用时在终端 **Ctrl+C** 停掉即可。

## 九、数据存在哪里？

所有运行数据在 **`pipeline/data/`**（不会上传到 Git）：

| 路径 | 内容 |
|------|------|
| `pipeline/data/serp_working.csv` | 当前工作区报表 |
| `pipeline/data/pipeline.db` | 打标结果数据库 |
| `pipeline/data/history/` | 搜索记录归档 |
| `pipeline/data/browser_profile/` | 百度登录态 / Cookie |
| `~/Library/Caches/ms-playwright` | Chromium 浏览器（约 1GB） |

## 十、常见问题

### Q1：双击 `.command` 闪退？

- 右键 → **打开** → 确认
- 或在终端手动运行：
  ```bash
  cd /你的项目路径
  ./mac/install.sh
  ```

### Q2：提示找不到 Python / Playwright？

重新双击 **`Mac一键安装.command`** 跑一遍安装流程。

### Q3：端口 8878 被占用？

```bash
lsof -ti:8878 | xargs kill -9
```
然后重新启动 SearchPipe。

### Q4：浏览器没弹出来？

- 检查是否误勾了 **「无头模式」**
- 确认 `~/Library/Caches/ms-playwright` 下有 Chromium

### Q5：打标很多失败？

正常现象。很多百度结果站已失效。建议：
- 保持 **快速模式** 勾选
- **不要勾** Crawl4AI
- 并发降到 4

### Q6：换一台 Mac 怎么用？

**最简单（一条命令）：**
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Punk2025/sousuo-/main/mac/bootstrap.sh)"
```

或拷贝项目文件夹后双击 **`Mac一键安装.command`**。  
**不用**拷贝 `.venv` 和浏览器缓存，在新电脑上重新装即可。

### Q7：怎么彻底卸载？

```bash
# 删项目文件夹
rm -rf /path/to/搜索网

# 可选：删浏览器缓存（约 1GB）
rm -rf ~/Library/Caches/ms-playwright

# 可选：删 Homebrew 装的 Python（若只为本项目装的）
brew uninstall python@3.12
```
