关于本演示站

本目录用于对照常见「情感 SEO 门户」的页面骨架，品牌与文案均为原创演示内容。

能做什么

静态 HTML + CSS + 少量 JS；可直接放到 nginx / Cloudflare Pages / 任意静态托管。

刻意不做

不接外域广告跳转、不接加密脚本、不做登录发帖。需要真论坛请用 Discourse / 自建社区产品。

本地预览（带后台）：在 portal 目录执行 ./start-admin.sh，打开 http://127.0.0.1:8767/admin/ （默认密码 admin123）。H5 导航：http://127.0.0.1:8767/nav/
